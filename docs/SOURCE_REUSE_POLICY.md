# Source reuse policy

This public repository starts from independently written contracts and tests.

Do not copy implementation source, tests, UI, schemas, documentation, or other copyrighted material from a private or third-party repository until all of the following are established:

1. exact source identity and provenance;
2. publication/reuse rights for the complete dependency chain;
3. required license and attribution notices;
4. a reviewed file-level source ledger;
5. a secret/private-state scan.

Historical runtime state, credentials, customer/project data, private backup material, absolute machine paths and protected configuration are never source-reuse candidates.
