# RDC-web-build-backend

Public source for the managed website lifecycle of RDC Website Studio.

## Responsibility
- Project/workspace registry and state.
- Change transactions, snapshots, history and rollback.
- Build/validation evidence and identity-bound Development Preview.
- Asset/Media Library lifecycle.
- Review/Preview Panel state and human decisions.
- Accepted state, immutable Release Prepare and explicit Release Activate.
- Backend/data adapters for approved full-stack capabilities.

## Project types
`static_web`, `node_web_app`, and `fullstack_app`.

## Current status
Bootstrap only. No Codebase implementation source is copied here yet.

## Development
```bash
npm test
npm run check
```

Preview is not acceptance. Acceptance is not publication. Release preparation is not release activation.
